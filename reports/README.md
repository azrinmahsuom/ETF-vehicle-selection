# reports/

Final, reader-facing output. This folder is committed.

- `report.md` — the full write-up (optional; for short projects the root README is enough).
- `figures/` — PNG charts referenced from the README. Save at 150–200 dpi, 1200px wide.

Every chart needs: a title that states the takeaway, labelled axes with units, the period covered, and a source line.
